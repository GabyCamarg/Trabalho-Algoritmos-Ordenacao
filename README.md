# Trabalho - Algoritmos de Ordenação

Implementação de cinco algoritmos de ordenação utilizando C++.

## Algoritmos

1. Bubble Sort
2. Selection Sort
3. Insertion Sort
4. Merge Sort
5. Quick Sort

## Testes

Todos os algoritmos foram testados utilizando o vetor:

[5, 3, 8, 1]

Os programas apresentam o vetor original, o resultado ordenado e a quantidade de comparações e trocas ou movimentações.

## Arquivos

- bubble_sort.cpp
- selection_sort.cpp
- insertion_sort.cpp
- merge_sort.cpp
- quick_sort.cpp
- testes_de_mesa_algoritmos_ordenacao.pdf

## Compilação

Exemplo para compilar o Bubble Sort:

g++ bubble_sort.cpp -o bubble_sort

./bubble_sort
